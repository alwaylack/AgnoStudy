# Agno Lesson Planner

Use this skill when the user asks for the next Agno lesson, a course recap, or a small practice plan.

## Workflow

1. Identify the current lesson topic.
2. Summarize the key concept in 2-3 sentences.
3. Suggest one minimal runnable practice.
4. Name the next lesson in the official learning path.

## Style

- Keep the answer short and practical.
- Prefer one runnable example over broad theory.
- Mention assumptions when progress information is incomplete.
